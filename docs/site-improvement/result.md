## Edwin 확인 필요 — 지어내지 않고 비워 두거나 원문대로 둔 것

**급한 것**
1. **바우처 페이지에 공개돼 있던 호출 키 교체**: Supabase 함수 `maumtown-contact`·`maumtown-email` 이 받던 `x-api-key` 값이 예전 커밋과 운영 사이트에 공개돼 있었다. 스크립트는 지웠지만 서버 쪽에서 키를 바꾸거나 함수를 막아야 한다 (센터 명의 문자 발송 가능성)
2. **홈 후기 4번 숨김**: 자살 시도 상세 묘사 + 탈북·지역 기관·날짜 등 신원 추정 정보. 주석으로 남겨 둠 — 다시 올릴지 센터장 판단
3. 예약절차 페이지의 개인 명의 계좌·개인 휴대폰 공개 여부

**사실 확인**
4. "since 2003"의 기준, 서울 지점 운영 여부·번호(02-851-1934 vs 02-825-1934)
5. 직함: 부원장 4명, 김유진 "부원장"인데 "현) 상담사", 홈·상담진 사이 현/전 불일치(상담진 페이지 원문 기준으로 맞춤)
6. 자격 표기: 김애숙·전창순 "임상심리사(보건복지부)" → 배지는 "임상심리사 N급(국가기술자격)"으로 씀. 송은미 "정신보건임상심리사 2급"(옛 명칭) 그대로. 김명숙 "여성심리사 1급" 발급 학회(한국심리학회 vs 한국여성심리학회)
7. 상담진 분야 배치: 남상철·김애숙 → 성인, 유진숙 → 아동·청소년(전문분야 문구가 원장 것 복사로 보임)
8. 개인상담 페이지: 마음챙김·SE 담당자 근거 없음(이름 없이 둠), 김애숙 정신역동 근거가 논문 1편, FAQ 문구("건강보험 청구 안 됨", 비밀보장 예외, "원하는 상담사를 예약 때 말씀") 운영 사실
9. 마음동네 이야기 5장: 저서·협약기관 목록 — 사이트에 있던 것만 썼다. 협약기관 로고·센터장 추가 경력이 있으면 채울 것
10. 사진 화질: 황호춘 112px, 송은미 142px — 재촬영 권장(모든 상담사 같은 배경·비율)
